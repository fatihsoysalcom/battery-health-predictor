# Battery Health Predictor

This Python script simulates a simplified BatteryIQ system. It models a battery's charge, health, and cycle count, and uses basic logic to predict remaining life and analyze performance, mimicking the core concept of an AI-driven battery management system.

## Language

`python`

## How to Run

Save the code as `battery_iq_demo.py` and run it from your terminal using: `python battery_iq_demo.py`
